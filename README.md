# 📊 Social Media Analysis – Instagram

> **SQL-driven social media analytics project focused on user behavior, engagement, content performance, and marketing insights.**

## 📌 Project Overview

This project analyzes Instagram user activity and engagement data using a **relational database containing 7 interconnected tables** covering users, posts, likes, comments, follows, and hashtags.

The primary analysis was performed using **SQL**, while SQL outputs were exported to CSV and visualized using **Microsoft Excel** to communicate key findings and recommendations.

## 🎯 Business Objective

The objective is to understand user behavior and engagement patterns and use those insights to support strategies for:

- 📈 Increasing user engagement
- 🔄 Improving user retention
- 👥 Supporting user acquisition
- 📣 Optimizing marketing and campaign strategies
- #️⃣ Identifying trending content and hashtags

## 🛠️ Tools & Technologies

- 🗄️ **SQL** – Data exploration, transformation, and analysis
- 📊 **Microsoft Excel** – Data visualization
- 📄 **CSV** – Exporting SQL outputs for visualization

## 🔍 Key Analysis

- 👤 Analyzed user activity using **likes, comments, and posts**.
- 🏷️ Segmented users into **Inactive, Moderately Active, and Highly Active** categories.
- 🏆 Identified **top-engaging users** who could be potential creators, influencers, or brand ambassadors.
- 📅 Analyzed **monthly engagement patterns** to identify suitable periods for marketing campaigns.
- #️⃣ Evaluated **hashtag usage and popularity** to identify trending topics and content opportunities.
- 🔄 Identified inactive users as a potential target group for re-engagement strategies.

## 💻 SQL Techniques Used

The project demonstrates practical use of:

- `JOINs`
- `CTEs (Common Table Expressions)`
- `Window Functions`
- `Aggregate Functions`
- `CASE` / Conditional Logic
- Ranking Functions
- Filtering and grouping
- Data-quality checks for NULL values and duplicates

## 💡 Key Insights

- 📊 Most users fall within the **Moderately Active** segment.
- ⚠️ Approximately **13% of users were identified as inactive** based on their platform activity.
- ⭐ High-engagement users can be considered potential creators, influencers, or brand ambassadors.
- 📅 Monthly engagement analysis can help identify opportunities for marketing campaigns.
- #️⃣ Popular and trending hashtags can be leveraged to improve content reach and participation.

## 🚀 Strategic Recommendations

1. 🔄 **Re-engage inactive users** through personalized campaigns, content recommendations, and incentives.
2. ⭐ **Leverage high-engagement users** for creator, influencer, and brand-ambassador opportunities.
3. #️⃣ **Promote trending hashtags** and recommend relevant hashtags during content creation.
4. ✍️ **Encourage content creation** through posting streaks, rewards, prompts, and gamification.
5. 📅 **Optimize campaign timing** by scheduling promotions and creator collaborations during high-engagement periods.
